## Regras permanentes do projeto

Estas regras valem para **todas as etapas futuras** deste projeto e devem ser seguidas sem exceção:

1. **Stack tecnológica**: apenas HTML, CSS, JavaScript puro (vanilla), Tauri e arquivos JSON.
   - Não usar React, Vue, Angular, TypeScript ou qualquer banco de dados.
   - Persistência de dados deve ser feita via arquivos JSON locais.
   - **App exclusivamente desktop**: nada de sincronização com a nuvem, backend externo, PWA ou qualquer outra plataforma além do executável Windows via Tauri. Essa exceção existiu entre a etapa de sincronização e a etapa de simplificação (ver histórico) e foi revogada — não reintroduzir sem pedido explícito e novo.
2. **Idioma**: todo o aplicativo (interface, textos, mensagens) deve ser em português.
3. **Design**: moderno, bonito, minimalista, sempre em dark mode.
4. **Escopo**: não adicionar funcionalidades que não tenham sido solicitadas explicitamente.
   - Se houver uma sugestão de melhoria ou funcionalidade extra, perguntar antes de implementar.
5. **Organização**: o projeto deve ser extremamente organizado e fácil de modificar no futuro.
   - Preservar compatibilidade com futuras alterações feitas por IA (código legível, bem estruturado, sem gambiarras).
6. **Fluxo de trabalho**: trabalhar sempre em etapas pequenas e parar ao final de cada etapa, aguardando aprovação antes de continuar.
7. **Transparência técnica**: sempre explicar o motivo das decisões técnicas tomadas.
8. **Quando algo não for possível**: se algo não puder ser feito exatamente como solicitado, explicar o motivo e propor a alternativa mais próxima possível.
