              Exportação

              Copie, exporte, faça backup e restaure seus dados

              Exportar em JSON

              Gera um único arquivo .json com todos os seus dados (ganhos, gastos, lembretes, metas e configurações). Útil para guardar ou para restaurar depois.

              Exportar em texto (para IA)

              Gera um arquivo .txt com um resumo legível dos seus dados, pronto para colar em uma IA e pedir análise ou conselhos.

              Backup manual

              Cria uma pasta com uma cópia completa e separada de cada arquivo de dados, em um local à sua escolha (ex: pendrive, OneDrive).

              Restaurar de um arquivo exportado

              Escolha um arquivo .json gerado por "Exportar em JSON" para substituir todos os dados atuais por ele.

              Backups automáticos recentes

              Criados sozinhos pelo app a cada alteração (últimos 15 por arquivo). Clique em "Restaurar" para voltar um arquivo específico a essa versão.

                Apagar todos os dados

                Apaga permanentemente todos os ganhos, gastos, lembretes e metas cadastrados (de todos os meses). As configurações não são afetadas. Um backup completo é criado automaticamente antes de apagar.
